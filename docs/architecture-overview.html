Connection Profile
Named source that groups all settings for one API. Stores the base URL, authentication type, default headers, SSL verification, and request timeout.
Endpoints
Each endpoint is one URL path within the API — equivalent to a table in a database source. Configured with HTTP method, query params, path variables, and where the data lives in the response.
Pagination Config
Tells the engine how to page through the data: which strategy to use, how large each page is, and hard limits on total pages and records fetched.

6 Auth Types Supported
No Auth · API Key (header or query) · Basic Auth · Bearer Token · OAuth Client Credentials · OAuth Authorization Code. The right handler is selected automatically per profile.
Credential Vault
All secrets are encrypted at rest. Credentials are decrypted in memory only at request time, injected into the HTTP call, and never written to logs or API responses.
Connection Validator
6-step diagnostic run on demand: DNS resolution → network connectivity → auth injection → HTTP response → format detection → response sample. Each step returns a plain-English result.

Pagination Engine
Handles all 6 strategies: Offset-Limit · Page-Size · Cursor · Next URL · Link Header · None. Fetches every page automatically until the dataset is complete.
Safety Limits
Hard caps on total pages and records are enforced unconditionally. Failed requests are retried with exponential backoff. Runaway pagination is impossible.
Response Guard
Each response is validated before processing. Binary files, executables, and non-JSON content are rejected at the boundary — nothing harmful enters the pipeline.

Schema Inference
Column names and data types are auto-detected from the live API response. Handles nested JSON, arrays, nulls, and mixed types. No manual schema definition needed.
Field Selection
Users review discovered columns, select which to include, set display names, and override inferred types if needed. The endpoint then looks exactly like a database table.
Transform → Load
Data flows into the existing transformation and loading pipeline unchanged. RDBMS · NoSQL · S3 · and more. No special handling required downstream.
